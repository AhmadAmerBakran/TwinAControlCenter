Start Here

For a normal first installation, complete these steps in order.

1. Start TWIN A

  1. Double-click the TWIN A Control Center desktop shortcut.
  2. Wait a few seconds for the launcher, Control Server and Desktop Agent.
  3. If needed, open http://127.0.0.1:5055 on the PC.

2. Check the dashboard

  • PC should become online.
  • Desktop Agent should become online.
  • OBS may stay offline until OBS is opened and configured.

3. Connect Tailscale

Sign in on the PC and iPad with the same permitted Tailscale account/tailnet.

tailscale status

4. Publish privately

tailscale serve --bg 5055
tailscale serve status

5. Add to iPad Home Screen

  1. Open the private https://...ts.net address in Safari.
  2. Tap Share → Add to Home Screen.
  3. Launch TWIN A from the new Home Screen icon.
Do not expose TWIN A port 5055 through public router port forwarding.

Installation

What the Windows installer provides and what is optional.

TWIN A core

  • Control Server
  • Desktop Agent
  • Windows Launcher/tray
  • Web dashboard/PWA
  • This Help Center

The normal installed app is self-contained; end users do not need the .NET SDK or Node.js.

Optional companions

  • Tailscale — private iPad access.
  • OBS Studio — recording/replay/scenes.
  • Steam — library discovery.
  • Discord — supported shortcuts/integration.

Desktop shortcut

The Windows installer creates the TWIN A shortcut with the TWIN A application icon. Double-click it to start/open the Control Center.

User configuration

%LOCALAPPDATA%\TwinAControlCenter\config.json

Back this file up before a clean Windows reinstall if you want to keep custom games, projects, flows and IoT settings.

iPad & Tailscale

Use this when the PC dashboard works but the iPad cannot connect.

PC checks

tailscale status
tailscale serve status

Tailscale should be connected and Serve should forward private HTTPS traffic to TWIN A.

iPad checks

  1. Confirm Tailscale is connected.
  2. Confirm the same permitted tailnet/account.
  3. Test the exact .ts.net address in Safari.
  4. If Safari works but the Home Screen app is stale, remove and re-add its Home Screen icon.

Recreate Serve

tailscale serve --bg 5055
tailscale serve status

Test locally first

http://127.0.0.1:5055/api/health

If this is unavailable on the PC, restart TWIN A before troubleshooting Tailscale.

OBS Studio

Use this when OBS is offline or Studio controls are unavailable.

Enable WebSocket

  1. Open OBS.
  2. Tools → WebSocket Server Settings.
  3. Enable the server on port 4455.
  4. Enable authentication and choose your password.

Store the password safely

Use the TWIN A tray menu → Configure OBS Password. TWIN A stores it locally in the Windows user environment rather than in source code.

Still offline?

  • Verify port 4455.
  • Re-enter the password through the tray.
  • Restart OBS, then TWIN A.

Empty scenes/mixer

TWIN A reads real OBS scenes and audio-capable inputs. It does not invent fake sources.

Remote Screen

Private desktop viewing with optional Windows input.

Gestures

1 tapLeft click
2 tapsDouble click
HoldRight click
DragMouse drag
2 fingersScroll
Pinch zoom is intentionally not part of Remote Screen.

View only vs control

The stream can remain view-only. Enable remote control only when you want the iPad to inject mouse/keyboard input.

Low FPS / latency

  • Try BALANCED mode.
  • Check iPad Wi-Fi quality.
  • Check PC load.
  • Choose one display instead of All Displays if needed.

Why input is amber

Windows can accept injected input but cannot prove what every target app did with it, so raw remote input is correctly reported as state-unverified.

Audio & Discord

Windows audio can usually be read back; Discord has stricter API limits.

Windows master audio

Master volume/mute are read from the active Windows endpoint and sync back when changed locally.

Output and microphone

TWIN A changes the Windows default endpoint. Apps pinned to a specific device can keep their own route.

Per-app mixer

Desktop → App Mixer uses actual Windows audio sessions and reads back supported volume/mute state.

Discord

Mute, deafen and Soundboard opening use native client actions. Discord does not expose reliable final mute/deafen state externally, so those actions remain state-unverified.

Games, Files & Dev

How the remaining major areas behave.

Games

Steam titles are discovered from real Steam libraries. For custom games, add a process name when possible to enable stronger launch verification.

Files

Ready drives are browsable. Windows/system paths and drive roots are protected against destructive mutations by default.

Dev

The installed app is self-contained. SDKs/toolchains are only needed for developer projects you explicitly configure.

Flows & IoT

Flows execute real commands. MQTT devices are never simulated; state topics allow verification when the real device reports the expected state.

Status & Security

The color/status language is deliberately strict.

VERIFIED

The action ran and the resulting state was independently confirmed.

EXECUTED • STATE UNVERIFIED

The action was sent successfully, but the target exposes no trustworthy final-state confirmation.

FAILED

The action failed, the target was unavailable, or required verification did not succeed.

Private access

TWIN A is intended to remain local/private and be reached from the iPad through Tailscale rather than a public server port.

Troubleshooting

Match the symptom, then test from the inside out.

Shortcut opens nothing

  1. Look for the TWIN A tray icon.
  2. Run the shortcut again.
  3. Test 127.0.0.1:5055/api/health.
  4. If still unavailable, repair/reinstall TWIN A.

PC works, iPad does not

  1. Check Tailscale on both devices.
  2. Check Serve status.
  3. Test the .ts.net URL in Safari.
  4. Re-add the PWA if only the Home Screen copy is stale.

Remote screen is black

  • Confirm Desktop Agent is online.
  • Refresh Desktop.
  • Try one display.
  • Restart TWIN A from the tray.

Steam title missing

Confirm it is installed in Steam, then use Games → Rescan. TWIN A discovers actual Steam metadata.

Still stuck?

Keep the exact red/amber message and the tab/action that produced it. For CI/build problems, keep the exact failing workflow step and error line.

Update & Recovery

Preserve user configuration through upgrades or a clean Windows reinstall.

Before reinstalling Windows

%LOCALAPPDATA%\TwinAControlCenter\config.json

Back it up. Also keep the OBS/MQTT credentials you will need to re-enter locally.

After reinstall

  1. Install TWIN A.
  2. Restore config if desired.
  3. Reconnect Tailscale.
  4. Recreate Tailscale Serve.
  5. Reconfigure OBS password.
  6. Verify local health, then iPad access.

Updating TWIN A

Install the newer official GitHub Release installer. Keep a config backup before major changes.

Uninstalling

Use Windows Installed Apps / Apps & Features. The uninstaller stops TWIN A processes before removing program files.
